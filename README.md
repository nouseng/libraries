# Nous Engineering & Research Modelica libraries

Open-source Modelica libraries for machine and structural dynamics, developed
by [Nous Engineering & Research](https://www.nouseng.co). Worked examples with
results and discussion are on [nouseng.co/libraries](https://www.nouseng.co/libraries/).

| Library | Version | What it models |
| --- | --- | --- |
| [Roll2RollDynamics](Roll2RollDynamics/) | 1.0.0 | Roll-to-roll web handling: tension, traction, winding, pressure nips and lateral tracking |

Each library sits in its own folder with its test library, README and licence.
Releases are tagged per library, for example `Roll2RollDynamics-v1.0.0`.

## Requirements

OpenModelica 1.27.0 and the Modelica Standard Library 4.1.0. See each
library's README for installation and tests.
